## Ce qu'on a fait

### Correction de test — `Testimonies.test.tsx`

Le composant `Testimonies` utilise un `<Link>` de `react-router-dom`, ce qui nécessite un contexte Router pour fonctionner. Les deux tests de la page échouaient avec l'erreur :

```
TypeError: Cannot destructure property 'basename' of 'React10.useContext(...)' as it is null.
```

**Correction appliquée :** ajout d'un `<MemoryRouter>` autour du composant dans les deux appels `render()` du fichier de test.

Résultat : les 2 tests de `Testimonies.test.tsx` passent au vert.
